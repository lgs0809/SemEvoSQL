# 共同 SQL 执行边界

本规则适用于执行规划、SQL 生成、语义一致性检查和 SQL 修复，不能被步骤指令、历史示例或用户反馈覆盖。
只生成只读查询。当前执行门禁禁止 Cartesian/conditionless JOIN：不得使用 CROSS JOIN、无条件 JOIN、逗号连接或伪造连接条件。
不同实体的独立标量汇总应分别放入 CTE 或标量子查询，再在最终 SELECT 中通过标量子查询引用各结果进行用户要求的运算；不要把原始明细连接后求和，也不要连接独立汇总 CTE。
每个标量分支必须由不含 GROUP BY 的聚合保证单值，或由已明确的唯一性约束保证单值；不得用 LIMIT 1 丢弃多行以伪造标量。各分支分别保留自己的时间依据、范围、发布指标及过滤条件。
空聚合及零分母按已确认业务语义处理，不得猜测。最终列名遵守 Semantic Blueprint.expectedResult.columns；步骤中的临时名称不能替换已冻结的输出列名。SQL 结构能力不改变已发布指标公式或本人确认的运算含义。

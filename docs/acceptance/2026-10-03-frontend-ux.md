# 前端 UX 候选与页面验收

本轮完成工作台视觉、页面导航与前端模块整理，候选为 web16，后端保持 immutable full16。剩余业务功能与大规模正式验收按要求暂停；浏览页面不算新的模型、查询、初始化或公共发布成功。

## 变更

工作区统一页头、侧栏、当前项目位置、步骤指引和移动端布局。项目详情保留全局导航，查询页保持专注布局；业务模型准备和模型改进建议分别使用 `semantic`、`evolution` 地址。管理员和成员入口遵循现有角色，隐藏分区链接对成员回到项目概览；后端仍负责授权。

初始化入口说明从结构导出、资料准备到校验导入的正常流程；业务规则和个人口径通过自然语言描述。查询帮助说明本次、个人与项目建议的区别，旧会话明确显示原模型版本，失败查询保留失败提示和执行详情。发布页面说明校验、发布和激活的区别，窄屏建议卡也显示真实尝试次数。

原 `semevosql.ts` API 拆为8个领域模块、7组合同类型和统一HTTP入口，保留兼容导出。独立AST审计确认114方法、78类型和53公开类型，除同一operator读取改为显式领域调用外，请求合同不变。项目地址同步提取为纯规则和composable；主题从基础样式拆到 `workspace.css`。详见 [开发边界](../development/frontend-workspace.md)。

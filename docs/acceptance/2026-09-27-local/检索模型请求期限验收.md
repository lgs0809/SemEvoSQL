# 检索模型请求期限验收

对应 SQL-01／04、交接 B.7／B.9 的故障降级，以及导学 7.3 中 embedding 与 reranker **各自 5 秒请求预算**。该要求不是整个检索流程合计 5 秒。证据目录 E：`$LOCAL_EVIDENCE_ROOT/work/semevosql-20260927`。

## 修复

旧的两个客户端使用 RestClient／Apache 读超时，当前保存的模型配置为 60 秒；持续缓慢到达的响应体还可能延长等待。两个检索客户端改用 WebClient，对收到完整响应体的 Mono 设置整体期限，并在超时后取消 HTTP 订阅和关闭连接。有效预算为配置期限与 5 秒的较小值，包含获取连接、等待响应头及读取响应体；没有叠加聊天模型的连接重试。JSON 响应体上限 16 MiB。

保留 Qwen/Qwen3-VL-Embedding-2B／1024 与 Qwen/Qwen3-VL-Reranker-2B，未替换模型、配置、凭据、向量身份或现有索引。失败沿原路径降级：embedding 失败使用授权内 PostgreSQL FTS，reranker 失败使用授权内 RRF 候选；降级不豁免语义问询及执行保护。HTTP 取消不等于已证明第三方推理进程停止计算。

改动：`backend/src/main/java/cn/lgs/semevosql/service/aimodelconfig/{DynamicModelFactory,OpenAiCompatibleEmbeddingModel,HttpRerankModel}.java`；`semantic/retrieval/SemanticRetrievalIndexService.java` 中过时的 Exact/BM25 日志改为 PostgreSQL FTS。

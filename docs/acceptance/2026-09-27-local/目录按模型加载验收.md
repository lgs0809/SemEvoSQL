## 复现与代码

`catalog-loading-baseline-1.log`：2 项反例全部失败。旧候选组装按 physical_table 扩大已命中模型，连另一 datasource 同名表模型也被加入；超过既有 24 模型额度静默截去部分种子，没有报告不完整。

- SemanticCatalogRepository／MybatisSemanticCatalogRepository／SemEvoSQLSemanticCatalogMapper：按项目＋冻结版本＋模型身份批量加载模型、列、指标、维度、粒度、枚举、规则；关系按起点／终点读取相邻批次。全局规则独立于模型 IN 条件保留。摘要查询不读取 description／evidence，全数据源与表名集合只取身份列。
- SemanticBlueprintGenerationService：命中及已绑定历史模型保留 modelCode，不用 physical_table 扩充明确身份；邻域沿用现有两跳范围，按批访问并去重循环，模型预算溢出直接拒绝，不截断继续执行。无明确身份的旧表名入口只接受唯一匹配。历史模型读取去掉原先 limit(4)。
- SemanticBlueprintPipeline／SemanticCatalogApplicationService：历史与显式模型绑定实际传到候选加载，编译物化按模型；检索故障时的小目录回退只读 limit+1 条摘要，超出仍拒绝任意子集回退。
- SemanticCatalogCache.getForModels：查询子集直接读仓库，不拿全量缓存替代；编译、预检、执行、结果脱敏、运行提示词和案例资产指纹消费按需子集。原有全目录方法继续用于明确需要完整目录的管理／发布等消费者。
- SchemaRecallNode、SemanticBlueprintNode、SemanticExecutionNode、SqlGenerateNode、SemanticConsistencyNode、SqlExecuteNode、VerifiedQueryExecutionService、MultiSourceSqlExecutionService、MultiSourcePolicyService、QueryCaseCaptureService 与外部 MCP 执行入口对齐。已固定 Run／MCP 版本 hash 传到执行校验，不能对子集重新算全目录指纹。
- QueryExecutionEvidence 持久化加载项目／版本／权威 hash／模型身份、模型详情完整标记、预算截断标记和邻域深度；QueryRunErrorPresenter 给预算及身份变化提供可读错误。
- V42 只新增关系终点、粒度、枚举和规则的作用域索引，不更新业务数据。

权威 hash 读自 qw_project_version，加载前后复核；MyBatis hash 查询明确关闭缓存并刷新会话缓存，避免第二次读取返回旧值。代码不会将 Catalog 子集当完整 Catalog 重新生成 hash。

## 第二批：资产详情与摘要分页

- `SemanticCatalogLookupService` 按类型批量解析精确资产身份，每种类型一次查询，仅先读资产键与模型归属；关系保留两端，全局规则单独读。未知、停用、重复歧义身份及超过 24 模型的详情依赖明确拒绝，不静默取第一条。200 条去重资产引用为单次详情请求上限，可分次获取；摘要每页 1～100 条，额外读取 1 条判断 hasMore，以 modelCode 为游标。每次读取前后复核调用方提供的冻结 hash。
- 新增本地只读 HTTP 入口：`GET /api/semevosql/projects/{projectId}/versions/{versionId}/semantic-catalog/models?catalogHash=...&pageSize=20&afterModelCode=...`，及 `POST .../semantic-catalog/details`。详情体由 API 客户端使用 `{catalogHash, assets:[{assetType,assetKey}]}`；普通聊天用户仍然只输入自然语言，不填写这些内部参数。两接口在 boundedElastic 运行数据库读取。
- `ExternalSemanticQueryFacade` 的精确详情及计划组装复用该服务和已经加载的 snapshot；不再先 getCatalog 全量读取。当前公开 MCP 工具仍只有 query／query_status，未将此 facade 冒充已注册公开工具，更没有新增公开 MCP 接口。
- `V43__catalog_asset_lookup_indexes.sql` 新增列／枚举复合身份表达式索引和 grain_code 索引。只新增索引，不改资产内容。
- 本地权限当前仍是配置的单用户 operator；项目／版本完整性检查不能替代多用户对象 ACL。MCP facade 单测中模拟撤权验证二次检查钩子，不计为真实多人撤权验收。

`catalog-asset-lookup-tests-1.log` 保留新增测试括号书写错误导致的 checkstyle 解析失败；修正后 `catalog-asset-lookup-tests-2.log` 12 项真实 PG 测试通过。扩充分页与歧义用例后的 `catalog-asset-lookup-tests-3.log` 18 项通过（14 项 PG＋4 项既有 MCP 单测）。`catalog-asset-lookup-full-backend-1.log` 完整常规回归 387 项通过，含 3 项新增 facade 绑定／披露边界单测。
